# Student Grade Tracker

A console-based Java application that allows users to manage student grades and generate a summary report.

## 📌 Project Overview

The Student Grade Tracker is a simple Java application developed using Core Java concepts.

The application allows users to:

- Add student names and scores
- Store student data using ArrayList
- Display all students
- Calculate the average score
- Find the highest score
- Find the lowest score
- Display a summary report
- Validate scores between 0 and 100

## 🚀 Features

### 1. Add Student

Users can enter:

- Student name
- Student score

The score must be between `0` and `100`.

### 2. Display All Students

Displays all students along with their scores.

### 3. Summary Report

The application calculates and displays:

- Total number of students
- Average score
- Highest score
- Student with the highest score
- Lowest score
- Student with the lowest score

### 4. Input Validation

The application does not accept scores below `0` or above `100`.
